# Shap brand

The mark is the **shaka**: a closed hand with thumb and pinky out, the easy *howzit / all good*
greeting you see on building sites and beaches across South Africa. *Shap* is what you say with
it.

| File | Use |
|---|---|
| `shap-mark.svg` | The hand on its own (light backgrounds) |
| `shap-icon.svg` | App icon: the hand on slate, rounded square |

Colours: slate `#1F2B33`, hi-vis orange `#E8731C`, crease `#7A3507`, site-office paper `#F5F2ED`.
Typeface: Atkinson Hyperlegible Next (also used in the PDFs), shared with Sorted.
